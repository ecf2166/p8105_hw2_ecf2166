The NYC subway dataset contains information on each entrance and exit
for each subway station in NYC. After cleaning, the dataset has 1868
rows and 19 columns. The variables retained are: line, station_name,
station_latitude, station_longitude, route1, route2, route3, route4,
route5, route6, route7, route8, route9, route10, route11, entry,
vending, entrance_type, ada. To clean the data, I cleaned the variable
names using `janitor::clean_names()` to make them easier to work with,
selected the variables of interest (line, station name, station latitude
/ longitude, routes served, entry, vending, entrance type, and ADA
compliance), and converted the `entry` variable from character (YES /
NO) to logical (TRUE / FALSE). These data are not tidy: route
information is spread across the eleven columns `route1` through
`route11` (with `route8` through `route11` as numeric variables and
`route1` through `route7` as character variables) so the route is stored
in column names rather than as a single variable with one value per row.

## Reformatting

``` r
# First, have to make sure that all of the route variables are character.
nyc_subways = 
  nyc_subways |> 
  mutate(
    route8 = as.character(route8),
    route9 = as.character(route9),
    route10 = as.character(route10),
    route11 = as.character(route11)
  )

# using pivot_longer() to make one route number column and one route name column
nyc_subways_longer = 
  nyc_subways |> 
  pivot_longer(
    route1:route11,
    names_to = "route_number",
    names_prefix = "route",
    values_to = "route_name"
  )

# To answer the questions about the A train:
n_a_stations = 
  nyc_subways_longer |> 
  filter(route_name == "A") |> 
  distinct(line, station_name) |> 
  nrow()

n_a_ada = 
  nyc_subways_longer |> 
  filter(route_name == "A", ada) |> 
  distinct(line, station_name) |> 
  nrow()
```

60 distinct stations serve the A train. Of these, 17 are ADA compliant.

The `trash_df` dataframe combines the data from three trash wheels:
Mr. Trash Wheel, Professor Trash Wheel, and Gwynnda. After cleaning and
combining the three datasets, the final dataset contains 1188
observations with 15 variables. The variables retained are: wheel,
dumpster, month, year, date, weight_tons, volume_cubic_yards,
plastic_bottles, polystyrene, cigarette_butts, glass_bottles,
plastic_bags, wrappers, sports_balls, homes_powered. Key variables
include `wheel`, which identifies the trash wheel, `weight_tons` and
`volume_cubic_yards` for each dumpster, and counts of items collected
such as `plastic_bottles`, `cigarette_butts`, and `wrappers.` Not every
item is recorded for every wheel: `sports_balls` is only recorded for
Mr. Trash Wheel and `glass_bottles` is not recorded for Gwynnda, so
these are missing for the other wheels.

The total weight collected by Professor Trash Wheel is 282.26. Gwynnda
